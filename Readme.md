This is my very first GitHub repository!  
It's a *Profile Card UI* built using simple *HTML and CSS*.

## Project Overview

The profile card displays:

- A banner image
- Profile picture
- Name and profession
- Followers and following count
- A follow button
- A short bio

## Why I Made This

I'm learning web development and wanted to create something simple but visually appealing to practice my skills.  

## Technologies Used

- HTML5
- CSS3

1. Download or clone this repository.
2. Open index.html in your browser.
3. That's it — enjoy the design!
